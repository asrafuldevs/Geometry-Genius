# Geometry-Genius

Geometry-Genius is a simple and interactive geometry calculator web app.  
It helps users quickly calculate the area of common shapes and keeps track of calculation history.

## Live Demo

🔗 **Live Link:** https://mdasraful56.github.io/Geometry-Genius/

## Features

- Calculate area of Triangle
- Calculate area of Rectangle
- Calculate area of Parallelogram
- Calculate area of Rhombus
- Calculate area of Pentagon
- Calculate area of Ellipse
- Interactive UI for quick calculations

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript

## How to Use

1. Open the live link.
2. Enter the required dimensions for a shape.
3. Click the calculate button to get the area.
4. Repeat for other shapes as needed.
